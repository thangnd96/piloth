# /piloth:update

Nâng bản PilothOS đã init lên version của plugin hiện tại.

1. Confirm the project is initialized (`pilothOS/.initialized` exists). If not, tell the user to run `/piloth:init` first and stop.
2. Follow `pilothOS/skills/workflow/pilothos-update/SKILL.md` exactly — single source of truth for staging commands, plan shape and the preserve list.
